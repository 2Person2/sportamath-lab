# SportaMath Lab User Testing Plan

## Goal

Test whether students can understand math concepts more easily through sports simulations.

## Testers

- 2–3 middle or high school students
- Ideally at least one student who likes sports
- Ideally at least one student who does not usually enjoy math

## Tasks

1. Open the Project Overview page.
2. Try the Race Pacing Simulator.
3. Use Challenge Mode to create a pacing plan.
4. Try the Basketball Shot Probability module.
5. Use Challenge Mode to test a shot strategy.
6. Explain one math concept learned from the app.

## Questions

1. Was the app easy to understand?
2. Which module was more interesting?
3. Which part was confusing?
4. Did the graphs help you understand the math?
5. Did Challenge Mode make the app more engaging?
6. What feature should be improved or added next?

## Feedback to Collect

- Confusing instructions
- Bugs or errors
- Parts that feel too easy or too hard
- Suggestions for new sports or features
- Whether the app made the math feel more useful
